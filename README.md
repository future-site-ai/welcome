### 🛠 Want to contribute?
1. Pick a project and read its `CONTRIBUTING.md`.
2. Look for issues labelled **`good first issue`** or **`help wanted`**.
3. Comment on the issue to claim it, then open a pull request.

Questions and ideas are welcome too: open a **Discussion** or an **Issue** in the project's repository.
